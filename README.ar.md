# SmarTel — مساعد ذكي يردّ على عملائك من حسابك في تيليجرام (Telegram Business)

**اللغات:** [English](README.md) · العربية (هذا الملف) · [فارسی](README_FA.md)

هذا البوت يعمل بنفس أسلوب خدمة ChatPlace: تربط البوت بحسابك **Telegram Business**
مرة واحدة، فيصبح البوت يستقبل رسائل العملاء الواردة إلى حسابك و**يردّ نيابةً عنك**
باستخدام الذكاء الاصطناعي والمحتوى الذي تعلّمه له (أسعار، أوقات العمل، سياسات… إلخ).

مهم أن تعرف الفرق:

| | بوت عادي | **SmarTel** |
|---|---|---|
| من يراسله | الناس تراسل البوت | العملاء يراسلون **حسابك** والبوت يرد نيابةً عنك |
| طريقة الربط | يضغط المستخدم Start | تربطه من **إعدادات تيليجرام ← Telegram Business ← Chat Bots** |
| مصدر الردود | البوت نفسه | **حسابك التجاري** (رد رسمي من حسابك) |
| يحتاج تسجيل رقم/كود؟ | لا | **لا** — كل شيء عبر Bot API الرسمي (بدون Telethon أو Userbot) |

## التشغيل السريع (٧ خطوات)

### 1) أنشئ البوت في BotFather
1. افتح **@BotFather** في تيليجرام ← أرسل `/newbot`.
2. اختر اسمًا واسم مستخدم ينتهي بـ `bot` (مثال: `MyShopAssistantBot`).
3. انسخ **التوكن** (شكله: `123456789:AA...`).

### 2) شغّل البرنامج
```bash
git clone <رابط-المستودع> && cd Tg-bot-ai
python -m venv .venv && source .venv/bin/activate      # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
في التشغيل الأول سيسألك عن التوكن (الصقه)، ثم يطبع في الطرفية (Terminal) شيئًا مثل:

```
 OWNER CLAIM CODE (send this to your bot in Telegram):
     /start 7B31F90C
```

> اترك سؤال `OWNER_USER_ID` فارغًا — لا تحتاج معرفة رقمك. الكود المطبوع في الطرفية
> هو وسيلة تأكيد أنك صاحب البوت.

### 3) خُذ ملكية البوت
افتح البوت في تيليجرام وأرسل له:
```
/start 7B31F90C
```
(استبدله بالكود الظاهر عندك). ستصلك رسالة «You are now the owner». الملكية تُحفظ،
ولن تحتاج الكود مرة أخرى.

### 4) اختر مزوّد الذكاء الاصطناعي (بدون طرفية)
أرسل `/ai` للبوت ← اختر المزوّد ← الصق مفتاح API ← اختر الموديل ← اضغط
**Test connection**.

مزودون **مجانيون/رخيصون للتجربة**:
- **Google Gemini** — طبقة مجانية سخية (احصل على المفتاح من `aistudio.google.com`).
- **Groq** — سريع جدًا وبه طبقة مجانية (`console.groq.com`).
- **OpenRouter** — مفتاح واحد لعشرات الموديلات (فيه موديلات مجانية).
- **Ollama / LM Studio** — يعمل على جهازك بلا تكلفة (تحتاج جهازًا جيدًا).

مزودون مدفوعون: **OpenAI**، **Anthropic Claude**، **DeepSeek**، **Mistral**،
**xAI (Grok)**، **Together**، أو أي خدمة متوافقة مع OpenAI عبر خيار **custom**.

> إذا كان لديك اشتراك ChatGPT Plus، يمكن استخدامه بدل المفتاح عبر خيار
> **Codex CLI** (انظر آخر الملف).

### 5) شغّل «وضع الأعمال» في BotFather
1. **@BotFather** ← `/mybots` ← اختر بوتك.
2. **Bot Settings** ← **Business Mode** (في بعض النسخ يُسمى **Secretary Mode**).
3. اضغط **Turn on**.

> بدون هذه الخطوة لن يسمح لك تيليجرام بربط البوت بحسابك التجاري.

### 6) اربط البوت بحسابك في تيليجرام
من الحساب الذي سيردّ على العملاء (يحتاج Premium):
1. تيليجرام ← **الإعدادات (Settings)**.
2. **Telegram Business**.
3. **Chat Bots** (المحادثات/الروبوتات).
4. اكتب اسم المستخدم لبوتك (مثال: `@MyShopAssistantBot`).
5. اختر نطاق العمل: **All private chats except…** (مستحسن) أو محادثات محددة.
6. في **Bot Permissions** فعّل **«Allow bot to reply to messages»** ← خطوة إلزامية
   (بدونها يقرأ البوت الرسائل ولا يستطيع الرد).
7. احفظ (**Save**).

بمجرد نجاح الربط سيصلك إشعار من البوت: «Business connection enabled».

### 7) علّم البوت محتواك، ثم اختر وضع الرد
- **ردود جاهزة سريعة** (الأفضل للبداية — أسعار، توصيل، مواعيد):
  ```
  /faq_add سعر, كام, بكام, price :: أسعارنا تبدأ من 500 جنيه، والتوصيل 50 جنيه.
  ```
  الكلمات المفتاحية مفصولة بفواصل، ثم `::`، ثم الرد. عند تطابق الكلمات يُرسل الرد
  كما هو **بدون** تدخّل الذكاء الاصطناعي (يعني لا يخترع أسعارًا).
- **قاعدة معرفة للمواد الطويلة** (سياسات، كتالوج، ملف PDF/DOCX):
  `/kb_upload` ثم أرسل الملف، أو `/kb_add نص…`.
- **اسمك وشخصيتك ولغتك**: `/settings` ← **Persona & language** (اسم المساعد، اسم
  النشاط، وصف النشاط، النبرة، لغة الرد، التوقيع).
- **وضع الرد**: `/mode`
  - `draft` — البوت يكتب الرد ويطلب موافقتك (Send / Edit / Reject) — الأكثر أمانًا.
  - `auto` — يرد فورًا على العملاء.
  - `off` — صامت ويخبرك بكل رسالة فقط.

### اختبار أخير
من **حساب آخر** (ليس حسابك) أرسل رسالة إلى حسابك التجاري، ويجب أن يصلك الرد من
حسابك أنت. إذا احتجت، استخدم `/health` لفحص كل شيء، و`/aitest` لاختبار الذكاء
الاصطناعي، و`/status` لحالة ربط الحساب.

| الأمر | الوظيفة |
|---|---|
| `/setup` | **قائمة تحقق تفاعلية** من ٦ خطوات مع شرح كل خطوة داخل تيليجرام |

| `/mode` | `auto` / `draft` / `off` |
| `/faq` | قائمة الردود الجاهزة (`/faq_add`, `/faq_list`, `/faq_del`, `/faq_search`, `/faq_import`, `/faq_export`, `/faq_clear`) |
| `/kb` | قاعدة المعرفة (`/kb_add`, `/kb_upload`, `/kb_list`, `/kb_search`, `/kb_delete`, `/kb_clear`) |

| `/chats` · `/chat <id>` | آخر المحادثات وسجل كل محادثة |
| `/reply <id> النص` | أرسل رسالة بنفسك من حسابك التجاري (يتوقف البوت عن الرد في هذه المحادثة مؤقتًا) |
| `/takeover` · `/handback` | إيقاف/إعادة تشغيل الردود في محادثة معينة |
| `/stats` · `/health` · `/export` | إحصائيات، فحص شامل، نسخة احتياطية (JSON) |
| `/status` | حالة البوت والمزوّد والربط |

## ما يميّز البوت

- 🤖 **ردود ذكية بالعربية والإنجليزية وأي لغة يكتب بها العميل** (إعداد `reply_language = auto`).
- ✍️ **ردود موافقة قبل الإرسال (Draft)** مع أزرار **إرسال / تعديل / رفض / إيقاف المحادثة**.
- 📚 **قاعدة معرفة** من ملفات `.txt` `.md` `.pdf` `.docx` مع بحث ذكي (Embeddings) وبديل بحث بالكلمات.
- ⚡ **ردود جاهزة فورية** تتطابق مع كلمات مفتاحية — تُرسل حرفيًا بلا هلوسة.
- 🧠 **ذاكرة لكل عميل** على حدة (تصفيرها بـ `/memory_clear`).
- 🙋 **انسحاب تلقائي عند تدخلك**: لحظة أن تردّ بنفسك في أي محادثة، يتوقف البوت عنها 30 دقيقة (قابل للتغيير).
- 🚦 **حد رسائل لكل عميل** (20/ساعة افتراضيًا) لمنع الإزعاج، مع إيقاف تلقائي عند التجاوز.
- 🛡️ **توجيه المواضيع الحساسة** (شكاوى، استرداد، بيانات شخصية، مواضيع قانونية/طبية/مالية) إلى الموافقة اليدوية حتى في وضع الرد التلقائي.
- 🔐 **أمان**: التحكم للمالك فقط، تشفير المفاتيح المخزّنة (Fernet)، إخفاء الأسرار في السجلات، ولا تُصدَّر المفاتيح في النسخة الاحتياطية.
- 🧩 **١٣ مزوّد ذكاء اصطناعي** قابل للتبديل من داخل تيليجرام، بما فيها موديلات محلية مجانية.

## إعدادات مهمة تحتاجها

تُعدَّل من `/settings` (أو بأمر مباشر)، وتُحفظ في قاعدة بيانات SQLite:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `auto_reply_enabled` | `false` | الإرسال التلقائي للردود |
| `approval_mode_enabled` | `true` | اقتراح الردود للموافقة أولًا (draft) |
| `assistant_name` / `business_name` / `business_description` | فراغ | شخصية المساعد ومعلومات نشاطك |
| `tone` | `friendly` | نبرة الرد: ودّي، مهني، بسيط، مختصر، دافئ |
| `reply_language` | `auto` | `auto` = يرد بنفس لغة العميل، أو لغة ثابتة (`ar`, `en`, …) |
| `signature` | فراغ | توقيع يُضاف لكل رد |
| `max_reply_chars` | `900` | أقصى طول للرد الواحد |
| `disclose_ai` | `false` | هل يصرّح بأنه مساعد آلي عند السؤال المباشر |
| `custom_instructions` | فراغ | تعليمات إضافية تُضاف لكل رد (أو `/instructions`) |
| `faq_enabled` / `faq_direct_reply` | `true` | تشغيل الردود الجاهزة، وإرسال المطابق حرفيًا |
| `faq_match_threshold` | `60` | حساسية مطابقة الردود الجاهزة (%) |
| `kb_enabled` / `strict_kb_mode` | `true` / `false` | استخدام قاعدة المعرفة، ومنع الإجابة خارجها |
| `reply_debounce_seconds` | `1.0` | تجميع الرسائل السريعة في رد واحد |
| `typing_indicator` | `true` | إظهار «يكتب…» أثناء التوليد |
| `greet_new_customers` + `welcome_text` | `false` | رسالة ترحيب تلقائية لعميل جديد |
| `nontext_ack_message` | فراغ | رد تلقائي عند إرسال صورة/صوت بدون نص |
| `owner_takeover_pause_minutes` | `30` | مدة إيقاف البوت بعد ردك أنت |
| `max_messages_per_customer_per_hour` | `20` | حد الرسائل لكل عميل |
| `sensitive_requires_approval` | `true` | إجبار الموافقة على المواضيع الحساسة |

## الإعداد بالملف (`‎.env`) بدل الطرفية

لا تحتاج `.env` إن اتبعت الخطوات فوق (تكوين `/ai` داخل تيليجرام يكفي)، لكن إن
أردت التحكم بالكامل:

```env
BOT_TOKEN=123456789:AA...
# اختياري: اتركه فارغًا لاستخدام كود الملكية من الطرفية
OWNER_USER_ID=
ALLOW_OWNER_CLAIM=true

AI_PROVIDER=openai           # openai|anthropic|google|groq|openrouter|deepseek|mistral|xai|together|custom|ollama|lmstudio|codex
AI_API_KEY=sk-...
AI_MODEL=gpt-4.1-mini        # فارغ = الموديل الافتراضي للمزوّد
AI_BASE_URL=                 # للنماذج المحلية أو خدمة مخصّصة

SMARTEL_FERNET_KEY=          # مفتاح تشفير مفاتيح API المخزّنة (اختياري لكن مستحسن)
DEFAULT_AUTO_REPLY=false     # القيم الافتراضية عند أول تشغيل فقط
DEFAULT_APPROVAL_MODE=true
```

انسخ `.env.example` إلى `.env` واملأه. ولإعادة التهيئة لاحقًا: `python main.py --reset`.
ولفحص الإعداد دون تشغيل البوت: `python main.py --check`.

### استخدام اشتراك ChatGPT بدل مفتاح API (اختياري)
```bash
npm install -g @openai/codex
codex login                  # اختر "Sign in with ChatGPT"
```
ثم في `.env`: `MODEL_BACKEND=codex` (أو اختر مزوّد **Codex** من `/ai`). ملاحظة:
هذا المسار أبطأ من API، وحدود الاشتراك تنطبق، والبحث بالـ Embeddings غير متاح
(يعمل البحث بالكلمات المفتاحية تلقائيًا). راجع شروط استخدام OpenAI قبل استخدامه
لخدمة عملاء حقيقية.

## التشغيل الدائم (سيرفر / VPS / Docker)

**بـ Docker (الأسهل):**
```bash
cp .env.example .env      # املأ BOT_TOKEN والمفتاح
docker compose up -d --build
docker compose logs -f    # لمشاهدة كود الملكية في أول تشغيل
```

**بـ systemd على سيرفر Linux:**
```ini
# /etc/systemd/system/smartel.service
[Unit]
Description=SmarTel Telegram Business assistant
After=network-online.target

[Service]
WorkingDirectory=/opt/Tg-bot-ai
ExecStart=/opt/Tg-bot-ai/.venv/bin/python main.py
Restart=always
RestartSec=5
User=smartel

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now smartel && journalctl -u smartel -f
```

⚠️ لا تشغّل نسختين من البوت بنفس التوكن في الوقت نفسه — تيليجرام يوقف الاثنين بخطأ
`409 Conflict`.

## استكشاف الأخطاء

| المشكلة | السبب والحل |
|---|---|
| لا تصلك أي رسالة من العملاء | تأكد من تشغيل **Business Mode** في BotFather، وأن الربط تم من **Telegram Business ← Chat Bots**، وأن حسابك **Premium**. |
| البوت يقرأ ولا يرد | فعّل **«Allow bot to reply to messages»** في صلاحيات البوت داخل إعدادات Telegram Business، وتأكد بـ `/status`. |
| يرد بلا ذكاء اصطناعي أو يعتذر | المفتاح غير صالح أو انتهى الرصيد: `/ai` ← **Test connection**، أو `/health`. |
| لا يرد في محادثة معيّنة | المحادثة موقوفة (تدخّل سابق) — `/chats` ثم إلغاء الإيقاف، أو `/handback <chat_id>`. |
| «409 Conflict» في السجلات | نسخة أخرى من البوت تعمل بنفس التوكن — أوقفها. |
| الردود لا تعرف معلوماتك | أضف المحتوى: `/faq_add` للأسئلة المتكررة و`/kb_upload` للملفات، أو ارفع `strict_kb_mode`. |
| الرد بصيغة غريبة أو مقطوع | ارفع `max_reply_chars` من `/settings`، أو اختر موديلًا أفضل من `/ai`. |
| نسيت كود الملكية | أوقف البوت وأعد تشغيله — يُطبع كود جديد (ما دام لم يُطالب بالملكية بعد). |

## الخصوصية والأمان

- البوت يستخدم **Telegram Bot API الرسمي** فقط: لا تسجيل برقم الهاتف، لا كود دخول،
  لا جلسة Userbot.
- الرسائل تُخزَّن محليًا في قاعدة بيانات SQLite على جهازك (`storage/smartel.db`) —
  لا تُرسل لأي طرف ثالث إلا لمزوّد الذكاء الاصطناعي الذي اخترته (لتوليد الرد فقط).
- المفاتيح تُخزَّن مشفّرة إذا ضبطت `SMARTEL_FERNET_KEY`، وتُخفى في السجلات، ولا
  تُصدَّر أبدًا في `/export`.
- التحكم بالبوت مقصور على المالك (رقمك أو كود الملكية)، وأي شخص آخر يراسل البوت
  مباشرة يحصل على رسالة توضيحية فقط.

## للمطوّرين

```bash
pip install -r requirements-dev.txt
pytest -q                     # كامل حزمة الاختبارات
pytest -q tests/integration   # اختبار تكاملي من التركيب حتى الرد
python main.py --check        # فحص الإعداد والاتصال دون تشغيل
```

البنية: `handlers/` (أوامر المالك، لوحات تيليجرام، مسار الرسائل الواردة)،
`services/` (الذكاء الاصطناعي ومزوّدوه، قاعدة المعرفة، الردود الجاهزة، الذاكرة،
الحدود، تجميع الرسائل)، `database.py` (SQLite)، `security.py` (الملكية)،
`telegram_api.py` (إرسال آمن مع تقسيم الرسائل وتصحيح HTML).

# Alfiqi Ai — مساعد للردود الشخصية على تيليجرام

**اللغات:** [English](README.md) · العربية (هذا الملف) · [فارسی](README_FA.md)

البوت **عربي بالكامل** من أول تشغيل: كل الشاشات والأزرار والإشعارات بالعربية،
والردود التي يكتبها نيابةً عنك بالعربية أيضًا (إلا إذا كتب الطرف الآخر بلغة أخرى).
ولتبديل اللغة: `/language` (أو `/language en`).

وله طريقتان للردّ:

| | الرسائل الخاصة للبوت (`/direct`) | Telegram Business |
|---|---|---|
| من يرد عليه | أي شخص يراسل **البوت نفسه** | الأشخاص الذين يراسلون **حسابك** |
| يحتاج Telegram Business / Premium | **لا** | نعم (+ وضع Secretary في BotFather) |
| الرد يصل من | البوت | **حسابك المرتبط** |
| التبديل | `/direct on\|off` (مفعّل افتراضيًا) | اربطه من Telegram Business ← Chat Bots |

الطريقتان تستخدمان نفس المحرّك: الردود الجاهزة وقاعدة المعرفة، وضع الرد
(`auto` / `draft` / `off`)، الموافقات، الإيقاف والتدخّل، حد المعدل، الذاكرة
والإحصائيات. ولإيقاف الردّ على الرسائل الخاصة تمامًا: `/direct off`.

الهدف هو **الردود الشخصية**، وليس متجرًا أو حساب خدمة عملاء. هوية المساعد
وتعليماته تستخدم اسم صاحب الحساب ونبذته وأولوياته الشخصية في كلا مساري الرد.
اسم **Telegram Business** هنا هو اسم واجهة الربط الرسمية لدى تيليجرام، وليس افتراضًا
بأن صاحب الحساب لديه نشاط تجاري. الرد على رسائل البوت نفسه لا يحتاج هذا الربط؛
أما الرد من حساب شخصي مرتبط فيظل خاضعًا لمتطلبات وصلاحيات Telegram Business.

### الاشتراك الإجباري والنجوم
- افتح `/gate` أو `/settings` ← بوابات الدخول ← الاشتراك الإجباري؛ يوجد زر
  **إضافة قناة/جروب** وزر تشغيل/إيقاف يتغير إلى الأخضر عند التفعيل.
- يقبل رابط قناة عامة مثل `https://t.me/channel` أو `@channel`.
  للقناة الخاصة أرسل: `-1001234567890 | اسم القناة | https://t.me/+invite`.
  أضف البوت مشرفًا في القناة ليتمكن من التحقق. تعذر التحقق لا يسمح بالمرور.
- من الرسائل المدفوعة اضبط السعر وعدد الرسائل المجانية. اجعل المجاني **0**
  لطلب الدفع من أول رسالة. تظهر المتطلبات للزائر عند `/start`، وتظهر فاتورة
  النجوم عند إرسال نص الرسالة. لا يمر النص ولا يُجاب عليه قبل تأكيد الدفع.
- فشل الفاتورة أو تفعيل الدفع دون سعر لا يسمح برسائل مجانية غير مقصودة.
- فحص الاشتراك وأزرار الانضمام يخصوا مراسلة **البوت نفسه**. أما الدفع بالنجوم
  فيعمل أيضًا داخل محادثة Telegram Business المرتبطة: الفاتورة تظهر في نفس محادثة
  حسابك، ولا يتحوّل العميل لشات البوت. ألوان الأزرار تحتاج إصدار تيليجرام يدعمها؛
  نص الحالة يظل ظاهرًا أيضًا.

مهم أن تعرف الفرق:

| | بوت عادي | **SmarTel** |
|---|---|---|
| من يراسله | الناس تراسل البوت | العملاء يراسلون **حسابك** والبوت يرد نيابةً عنك |
| طريقة الربط | يضغط المستخدم Start | تربطه من **إعدادات تيليجرام ← Telegram Business ← Chat Bots** |
| مصدر الردود | البوت نفسه | **حسابك المرتبط** (رد رسمي من حسابك) |
| يحتاج تسجيل رقم/كود؟ | لا | **لا** — كل شيء عبر Bot API الرسمي (بدون Telethon أو Userbot) |

## التشغيل السريع (٧ خطوات)

### 1) أنشئ البوت في BotFather
1. افتح **@BotFather** في تيليجرام ← أرسل `/newbot`.
2. اختر اسمًا واسم مستخدم ينتهي بـ `bot` (مثال: `MyShopAssistantBot`).
3. انسخ **التوكن** (شكله: `123456789:AA...`).

### 2) شغّل البرنامج
```bash
git clone <رابط-المستودع> && cd Tg-bot-ai
./start.sh          # لينكس/ماك — ينشئ البيئة ويثبّت المتطلبات ويشغّل البوت
start.bat           # ويندوز (انقر عليه مرتين)
```

أو يدويًا:
```bash
python -m venv .venv && source .venv/bin/activate      # ويندوز: .venv\Scripts\activate
pip install -r requirements.txt
python main.py
```
في التشغيل الأول سيسألك عن التوكن (الصقه)، ثم يطبع في الطرفية (Terminal) شيئًا مثل:

```
 OWNER CLAIM CODE (send this to your bot in Telegram):
     /start 7B31F90C
```

> اترك سؤال `OWNER_USER_ID` فارغًا — لا تحتاج معرفة رقمك. الكود المطبوع في الطرفية
> هو وسيلة تأكيد أنك صاحب البوت.

### 3) خُذ ملكية البوت
افتح البوت في تيليجرام وأرسل له:
```
/start 7B31F90C
```
(استبدله بالكود الظاهر عندك). ستصلك رسالة «You are now the owner». الملكية تُحفظ،
ولن تحتاج الكود مرة أخرى.

### 4) اختر مزوّد الذكاء الاصطناعي (بدون طرفية)
أرسل `/ai` للبوت ← اختر المزوّد ← الصق مفتاح API ← اختر الموديل ← اضغط
**Test connection**.

**ما عندك بطاقة بنكية ولا رصيد؟** أرسل `/freeai` — تظهر لك قائمة المزودين
المجانيين بالكامل، وضغطة واحدة تنقل البوت إليها وتطلب مفتاحها فورًا.

مزودون **مجانيون تمامًا (بدون بطاقة بنكية)**:
- **Google Gemini** 🆓 — أوسع طبقة مجانية؛ حساب جوجل يكفي
  (`aistudio.google.com/app/apikey`).
- **Groq** 🆓 — الأسرع، تسجيل بالإيميل فقط (`console.groq.com/keys`).
- **Cerebras** 🆓 — نحو مليون توكن يوميًا مجانًا (`cloud.cerebras.ai`).
- **OpenRouter** 🆓 — مفتاح واحد لمئات الموديلات؛ اختر موديلًا ينتهي بـ `:free`.
- **Mistral** 🆓، **NVIDIA NIM** 🆓، **SambaNova** 🆓، **Hugging Face** 🆓 —
  طبقات مجانية إضافية.
- **Pollinations** 🔓 — **بدون مفتاح إطلاقًا** (بطيء ومجهوده تطوعي: يصلح
  للتجربة الأولى لا لمحل مزدحم).
- **Ollama / LM Studio** 💻 — مجاني وخاص تمامًا، يعمل على جهازك (تحتاج جهازًا
  جيدًا).

مزودون مدفوعون (تحتاج **رصيدًا في حساب API**): **OpenAI**، **Anthropic Claude**،
**DeepSeek**، **xAI (Grok)**، **Together**، أو أي خدمة متوافقة مع OpenAI عبر خيار
**custom**.

> ⚠️ أهم سبب لرسالة «المفتاح لا يعمل»: اشتراك **ChatGPT Plus** أو **Claude Pro**
> ليس رصيد API. المفتاح الجديد من OpenAI لا يعمل إلا بعد شحن الرصيد في
> `platform.openai.com ← Billing`. لهذا وُجد `/freeai`.

بعدها اضغط **🧪 Test connection**. لو فشل الاختبار سيخبرك البوت **بالسبب بالتحديد**
(مفتاح مرفوض · لا يوجد رصيد · اسم موديل خاطئ · تجاوز الحد · دولتك محظورة) ويعرض
عليك أزرارًا للانتقال لمزوّد مجاني. ولو كانت المشكلة في اسم الموديل فقط، اضغط
**🔄 Load models from the provider** لترى الأسماء التي يسمح بها مفتاحك فعلًا.

> إذا كان لديك اشتراك ChatGPT Plus، يمكن استخدامه بدل المفتاح عبر خيار
> **Codex CLI** (انظر آخر الملف).

> الوصول للحد.

### 5) شغّل «وضع الأعمال» في BotFather
1. **@BotFather** ← `/mybots` ← اختر بوتك.
2. **Bot Settings** ← **Business Mode** (في بعض النسخ يُسمى **Secretary Mode**).
3. اضغط **Turn on**.

> بدون هذه الخطوة لن يسمح لك تيليجرام بربط البوت بحسابك التجاري.

### 6) اربط البوت بحسابك في تيليجرام
من الحساب الذي سيردّ على العملاء (يحتاج Premium):
1. تيليجرام ← **الإعدادات (Settings)**.
2. **Telegram Business**.
3. **Chat Bots** (المحادثات/الروبوتات).
4. اكتب اسم المستخدم لبوتك (مثال: `@MyShopAssistantBot`).
5. اختر نطاق العمل: **All private chats except…** (مستحسن) أو محادثات محددة.
6. في **Bot Permissions** فعّل **«Allow bot to reply to messages»** ← خطوة إلزامية
   (بدونها يقرأ البوت الرسائل ولا يستطيع الرد).
7. احفظ (**Save**).

بمجرد نجاح الربط سيصلك إشعار من البوت: «Business connection enabled».

### 7) علّم البوت محتواك، ثم اختر وضع الرد
- **ردود جاهزة سريعة** (الأفضل للبداية — أسعار، توصيل، مواعيد):
  ```
  /faq_add سعر, كام, بكام, price :: أسعارنا تبدأ من 500 جنيه، والتوصيل 50 جنيه.
  ```
  الكلمات المفتاحية مفصولة بفواصل، ثم `::`، ثم الرد.

  **كيف تتم المطابقة؟** الكلمات في السطر الواحد *بدائل* وليست شرطًا مجتمعًا: يكفي
  أن تظهر إحداها في رسالة العميل. المطابقة المباشرة (مثل «بكام» أو «السعر» مع
  «سعر») تُرسل ردك **حرفيًا بدون** أي تدخّل للذكاء الاصطناعي — فلا يمكن أن يخترع
  سعرًا. أما المطابقة بصيغة الكلمة (deliver مع delivery، أو orders مع order) فتُعطى
  للذكاء الاصطناعي كإجابة موثوقة ليصيغها بأسلوب طبيعي. اختبر أي صياغة بـ
  `/faq_search` وسيخبرك هل سيرد البوت فورًا أم لا.
- **قاعدة معرفة للمواد الطويلة** (سياسات، كتالوج، ملف PDF/DOCX):
  `/kb_upload` ثم أرسل الملف، أو `/kb_add نص…`.
- **اسمك وشخصيتك ولغتك**: `/settings` ← **Persona & language** (اسم المساعد، اسم
  النشاط، وصف النشاط، النبرة، لغة الرد، التوقيع).
- **وضع الرد**: `/mode`
  - `draft` — البوت يكتب الرد ويطلب موافقتك (Send / Edit / Reject) — الأكثر أمانًا.
  - `auto` — يرد فورًا على العملاء.
  - `off` — صامت ويخبرك بكل رسالة فقط.

### اختبار أخير
من **حساب آخر** (ليس حسابك) أرسل رسالة إلى حسابك التجاري، ويجب أن يصلك الرد من
حسابك أنت. إذا احتجت، استخدم `/health` لفحص كل شيء، و`/aitest` لاختبار الذكاء
الاصطناعي، و`/status` لحالة ربط الحساب.

| الأمر | الوظيفة |
|---|---|
| `/setup` | **قائمة تحقق تفاعلية** من ٦ خطوات مع شرح كل خطوة داخل تيليجرام |

| `/reply <id> النص` | أرسل رسالة بنفسك من حسابك التجاري (يتوقف البوت عن الرد في هذه المحادثة مؤقتًا) |
| `/takeover` · `/handback` | إيقاف/إعادة تشغيل الردود في محادثة معينة |
| `/stats` · `/health` · `/export` | إحصائيات، فحص شامل، نسخة احتياطية (JSON) |
| `/status` | حالة البوت والمزوّد والربط |
| `/admin <user_id>` · `/admin remove <user_id>` · `/admin list` | للأدمن الرئيسي فقط: إضافة/سحب مشرف وإدارة القائمة |
| `/help` | دليل الاستخدام |
| `/reset` · `/cancel` | تنظيف الحالات المعلّقة / إلغاء إدخال جارٍ |

### حسابات متعددة ومشرفون
الأدمن الرئيسي الوحيد هو Telegram user ID `5231453921`؛ اضبط `OWNER_USER_ID=5231453921`
في `.env`. هذا المعرّف فقط يستطيع استخدام `/admin <user_id>` لإضافة مشرف، تغيير
مزوّد/موديل الذكاء، وتحميل قائمة الموديلات.
المشرف المضاف يفتح البوت ويستخدم `/start`، وبعدها يربط حساب Telegram Business الخاص
به من **Telegram Settings → Business → Chatbots**. يجب أن يطابق معرّف مالك اتصال
Business رقم المشرف المضاف.

لكل مشرف قاعدة بيانات وإعدادات شخصية مستقلة: الهوية والأولويات،
قواعد «ما يرد عليه/ما لا يرد عليه»، الردود الجاهزة، قاعدة المعرفة، العملاء، المحادثات
والموافقات. تظهر حقول الهوية، **Reply priorities** و**When not to answer** من `/settings`؛
وتوجد كذلك خانة **Extra instructions** للتعليمات الإضافية. لا تظهر للمشرف أزرار تغيير المزوّد/الموديل؛ يحددها الأدمن الرئيسي،
مفتاح الذكاء الذي يضيفه المالك/الأدمن الرئيسي يُستخدم تلقائيًا لكل الحسابات المرتبطة،
ويُقرأ مركزيًا عند كل طلب؛ تغييره ينعكس مباشرة دون نسخه في قواعد بيانات المشرفين.
لا يظهر المفتاح للمشرفين، ولا تختلط محادثاتهم أو تعليماتهم الشخصية. يمكن الاحتفاظ
بمفتاح محلي احتياطي يُستخدم فقط عند عدم وجود مفتاح مركزي. حذف المشرف لمفتاحه
المحلي لا يحذف المفتاح المركزي. إزالة مشرف بـ `/admin remove <user_id>` توقف وصوله فورًا ولا تمسح بياناته؛ إعادة
إضافته تعيد وصوله إلى ملفه السابق. لا تُشارك ملفات قواعد البيانات أو النسخ الاحتياطية
يدويًا بين الحسابات.

**الواجهة الرسومية:** `/start` يفتح لوحة أزرار (الحالة، التشغيل/الإيقاف، الردود
الجاهزة، قاعدة المعرفة، الإعدادات، الموافقات المعلّقة، الذاكرة، المساعدة).

## ما يميّز البوت

- 🤖 **ردود ذكية بالعربية والإنجليزية وأي لغة يكتب بها العميل** (إعداد `reply_language = auto`).
- ✍️ **ردود موافقة قبل الإرسال (Draft)** مع أزرار **إرسال / تعديل / رفض / إيقاف المحادثة**.
- 📚 **قاعدة معرفة** من ملفات `.txt` `.md` `.pdf` `.docx` مع بحث ذكي (Embeddings) وبديل بحث بالكلمات.
- ⚡ **ردود جاهزة فورية** تتطابق مع كلمات مفتاحية — تُرسل حرفيًا بلا هلوسة.
- 🧠 **ذاكرة لكل عميل** على حدة (تصفيرها بـ `/memory_clear`).
- 🙋 **انسحاب تلقائي عند تدخلك**: لحظة أن تردّ بنفسك في أي محادثة، يتوقف البوت عنها 30 دقيقة (قابل للتغيير).
- 🚦 **حد رسائل لكل عميل** (20/ساعة افتراضيًا) لمنع الإزعاج، مع إيقاف تلقائي عند التجاوز.
- 🛡️ **توجيه المواضيع الحساسة** (شكاوى، استرداد، بيانات شخصية، مواضيع قانونية/طبية/مالية) إلى الموافقة اليدوية حتى في وضع الرد التلقائي.
- 🔐 **أمان**: التحكم للمالك فقط، تشفير المفاتيح المخزّنة (Fernet)، إخفاء الأسرار في السجلات، ولا تُصدَّر المفاتيح في النسخة الاحتياطية.
- 🧩 **١٨ مزوّد ذكاء اصطناعي** قابل للتبديل من داخل تيليجرام، منها **١٢ تعمل بلا أي تكلفة**.
- 🆓 **`/freeai`** — قائمة المزودين المجانيين (بلا بطاقة بنكية وبلا رصيد) مع حدود كل واحد، والتبديل بضغطة.
- 🧠 **قواعد موضوعات بأسلوبك** (`/rules`): ابعت التعليمات بكلامك العادي (الأسعار، التوصيل، المواعيد، «متقولش كذا»)، والذكاء الاصطناعي يقسّمها لقواعد موضوعات ويعرض عليك **مسودة** — مفيش حاجة تتطبق غير لما تعتمدها بضغطة ✅.
- ❓ **الأسئلة اللي معرفش يرد عليها** (`/unanswered`): بدل ما يخمّن، يقول للشخص إن الفريق هيرد عليه، ويبعتلك **أنت** السؤال. وإجابتك توصل لصاحب السؤال **وتتحفظ كرد جاهز**، فالسؤال نفسه ما يحتاجش الذكاء الاصطناعي تاني.
- 🔗 **مصادر يبحث فيها** (`/resources`): ضيف موقع أو منصة أو جروب/قناة تيليجرام أو نص. صفحات الويب بتتسحب لقاعدة المعرفة، وقائمة المراجع بتتوصل للمساعد علشان يبعت **روابط حقيقية** مش مخترعة.
- 🚪 **بوابات الدخول** (`/gate`) ومقفولة افتراضيًا: **الاشتراك الإجباري** في قنواتك/جروباتك يخص رسائل شات البوت (أزرار اشتراك + ✅ للتحقق، والنتيجة متخزنة ٥ دقايق)، و**الدفع بنجوم تيليجرام** يعمل في شات البوت أو داخل محادثة Telegram Business المرتبطة. في Business تظهر الفاتورة داخل محادثة العميل نفسها؛ أنت تضبط السعر وتقدر تسيب أول *N* رسائل مجانية، والرسالة لا تتسلّم قبل تأكيد الدفع. وأي رسالة تعدّي من بوابة توصلك منها نسخة (بمفتاح تشغيل/إيقاف).
- 🩺 **تشخيص دقيق للأعطال**: المفتاح المرفوض، ونفاد الرصيد، واسم الموديل الخاطئ، وتجاوز الحد المجاني، والحظر الجغرافي — كل واحدة لها رسالة وحل مختلف، مع **🔄 Load models** لجلب أسماء الموديلات التي يسمح بها مفتاحك فعلًا.

## إعدادات مهمة تحتاجها

تُعدَّل من `/settings` (أو بأمر مباشر)، وتُحفظ في قاعدة بيانات SQLite:

| الإعداد | الافتراضي | المعنى |
|---|---|---|
| `auto_reply_enabled` | `false` | الإرسال التلقائي للردود |
| `approval_mode_enabled` | `true` | اقتراح الردود للموافقة أولًا (draft) |
| `assistant_name` / `business_name` / `business_description` | فراغ | شخصية المساعد ومعلومات نشاطك |
| `tone` | `friendly` | نبرة الرد: ودّي، مهني، بسيط، مختصر، دافئ |
| `reply_language` | `auto` | `auto` = يرد بنفس لغة العميل، أو لغة ثابتة (`ar`, `en`, …) |
| `signature` | فراغ | توقيع يُضاف لكل رد |
| `max_reply_chars` | `900` | أقصى طول للرد الواحد |
| `disclose_ai` | `false` | هل يصرّح بأنه مساعد آلي عند السؤال المباشر |
| `custom_instructions` | فراغ | تعليمات إضافية تُضاف لكل رد (أو `/instructions`) |
| `faq_enabled` / `faq_direct_reply` | `true` | تشغيل الردود الجاهزة، وإرسال المطابق حرفيًا |
| `faq_match_threshold` | `60` | حساسية مطابقة الردود الجاهزة (%) |
| `kb_enabled` / `strict_kb_mode` | `true` / `false` | استخدام قاعدة المعرفة، ومنع الإجابة خارجها |
| `reply_debounce_seconds` | `1.0` | تجميع الرسائل السريعة في رد واحد |
| `typing_indicator` | `true` | إظهار «يكتب…» أثناء التوليد |
| `greet_new_customers` + `welcome_text` | `false` | ترحيب تلقائي بعميل جديد؛ غيّر النص من `/settings` ← «رسائل الترحيب والدفع» |
| `payment_message` | فراغ | النص قبل فاتورة النجوم؛ `{stars}` يدرج السعر تلقائيًا، من نفس قسم الإعدادات |
| `nontext_ack_message` | فراغ | رد تلقائي عند إرسال صورة/صوت بدون نص |
| `owner_takeover_pause_minutes` | `30` | مدة إيقاف البوت بعد ردك أنت |
| `max_messages_per_customer_per_hour` | `20` | حد الرسائل لكل عميل |
| `sensitive_requires_approval` | `true` | إجبار الموافقة على المواضيع الحساسة |
| `rules_enabled` | `true` | إضافة قواعد `/rules` المعتمدة لكل رد |
| `resources_enabled` | `true` | استخدام قائمة المصادر من `/resources` |
| `unanswered_enabled` | `true` | يقول «هسأل الفريق» ويسجّل السؤال في `/unanswered` |
| `require_subscription_enabled` | `false` | **بوابة:** لازم الاشتراك في قنواتك قبل الرد (القائمة من `/gate`) |
| `paid_messages_enabled` | `false` | **بوابة:** تحصيل نجوم تيليجرام مقابل كل رسالة |
| `paid_message_stars` | `0` | السعر اللي تكتبه — **‏0 يمنع الرسائل المدفوعة لحين ضبط السعر إذا كانت مفعّلة** |
| `paid_message_free_count` | `0` | عدد الرسائل المجانية قبل الدفع |
| `gate_copy_to_owner` | `true` | تبعتلك نسخة من أي رسالة عدّت من بوابة |

زر الوضع **OFF** يوقف توليد الردود والمسودات فعلًا. `auto_reply_enabled` هو المفتاح الرئيسي،
ووضع الموافقة يحدد شكل الرد فقط عندما يكون المفتاح الرئيسي مفعّلًا.

## بوابات الدخول والتعلّم

فحص الاشتراك يشتغل على **الرسائل الخاصة اللي الناس بتبعتها للبوت نفسه** (مسار
`/direct`). بوابة نجوم تيليجرام تشتغل على شات البوت، وكمان على حساب Telegram
Business المرتبط؛ الفاتورة تظهر للعميل داخل نفس محادثة الحساب.

### قواعد الموضوعات — `/rules`
ابعت تعليماتك في رسالة واحدة عادية (`/rules_add` أو زر ✍️):

```
/rules_add الأسعار ثابتة 500 جنيه، مفيش خصم من نفسك.
التوصيل داخل دمياط يومين، وخارجها 3-5 أيام.
لو حد سأل عن حاجة مش عارفها قولي.
```

الذكاء الاصطناعي يقسّمها لقواعد موضوعات ويعرض المسودة بأزرار:

| الزر | تأثيره |
| --- | --- |
| ✅ اعتماد وتطبيق | القواعد تشتغل وتتضاف لكل رد بعد كده |
| ✏️ عدّل | تبعت النص تاني والمسودة القديمة تتلغي |
| 🗑 إلغاء | المسودة تتشال ومفيش أي تغيير |

`/rules_list` تعرض كل القواعد مع ✅/⏸ (إيقاف مؤقت بدون حذف)، و`/rules_del <id>`
تحذف واحدة، و`/rules_clear` تفضّي القائمة. ولو مفيش مزوّد ذكاء اصطناعي شغّال،
التعليمات بتتقسّم محليًا سطر سطر — الشغل مايتوقفش على الموديل.

### الأسئلة بدون إجابة — `/unanswered`
لما المساعد مايكونش عنده إجابة، بيرد بعلامة `NO_ANSWER` بالظبط، والمسار بعدها يبعت
للشخص رسالة مهذبة «سألت حد من الفريق» ويوصلك **أنت** السؤال مع زر ✍️. إجابتك تروح
لصاحب السؤال **وتتحفظ كرد جاهز** (وتظهر في `/faq` كمان)، فالسؤال نفسه يتجاوب فوريًا
ومجانًا بعد كده. وتقدر تقفل السلوك ده من `unanswered_enabled`.

### المصادر — `/resources`
```
/resources_add https://example.com/prices | صفحة الأسعار | محدثة كل شهر
/resources_add https://t.me/mychannel
/resources_add استبدال خلال 14 يوم بفاتورة
```
صفحة الويب بتتسحب (مهلة ٨ ثواني، وروابط `t.me` بتتخطى السحب) وبتتخزن في قاعدة
المعرفة، والرابط نفسه بيفضل مرجع المساعد يقدر يبعته. و`/resources_list` بتوقف/تشغّل
أي مصدر.

### الاشتراك الإجباري — `/gate` ← 🔒
1. `/gate` ← **🔒 الاشتراك الإجباري** ← **➕ إضافة قناة/جروب**، وبعدها ابعت
   `@username` أو المعرّف الرقمي أو `@username | العنوان | رابط الدعوة`.
2. اضغط على صف البوابة لتشغيلها (`require_subscription_enabled`).

لازم البوت يكون **مشرف** في القناة علشان يقدر يقرا الاشتراك. واللي مشتركش بتوصله
أزرار اشتراك لكل قناة + زر **✅ تأكيد اشتراكي**، والنتيجة متخزنة ٥ دقايق. ولو البوت
**ماقدرش** يتحقق (مفيش صلاحية، أو خطأ شبكة) الرسالة تفضل محجوبة؛ تعذّر التحقق
مش إثبات اشتراك. راجع صلاحيات البوت ثم جرّب زر التحقق تاني.

### الرسائل المدفوعة (نجوم تيليجرام) — `/gate` ← ⭐
1. `/gate` ← **⭐ الرسائل المدفوعة** ← **💲 تحديد السعر** واكتب عدد النجوم (بكده
   تحدّد السعر وتفتح البوابة مع بعض).
2. واختياري **🎁 رسائل مجانية قبل الدفع** — دي بتعدّي من غير أي حجب.

النجوم مش محتاجة مزوّد دفع ولا بطاقة: الفاتورة بعملة `XTR`، والشخص بيدفع جوه تيليجرام،
والبوت يرد على `pre_checkout_query`، والرسالة المحفوظة ماتتسلّمش غير بعد
`successful_payment`. و`/gate` ← **📃 المطلوب حاليًا** تعرض المفاتيح والسعر وآخر
المدفوعات، والنسخة اللي بتوصلك فيها زر **↩️ استرجاع**. والرسالة **مابتتوصلش** قبل
الدفع. ولو تيليجرام رفض الفاتورة، يظل النص محفوظًا ومعلقًا مع زر إعادة محاولة الدفع؛
لا يتم الرد مجانًا.

## الإعداد بالملف (`‎.env`) بدل الطرفية

لا تحتاج `.env` إن اتبعت الخطوات فوق (تكوين `/ai` داخل تيليجرام يكفي)، لكن إن
أردت التحكم بالكامل:

```env
BOT_TOKEN=123456789:AA...
# اختياري: اتركه فارغًا لاستخدام كود الملكية من الطرفية
OWNER_USER_ID=
ALLOW_OWNER_CLAIM=true

BOT_LANGUAGE=ar              # لغة الواجهة: ar (افتراضي) | en — ويمكن تغييرها من تيليجرام بـ /language
AI_PROVIDER=openai           # openai|anthropic|google|groq|openrouter|deepseek|mistral|xai|together|custom|ollama|lmstudio|codex
AI_API_KEY=sk-...
AI_MODEL=gpt-4.1-mini        # فارغ = الموديل الافتراضي للمزوّد
AI_BASE_URL=                 # للنماذج المحلية أو خدمة مخصّصة

SMARTEL_FERNET_KEY=          # مفتاح تشفير مفاتيح API المخزّنة (اختياري لكن مستحسن)
DEFAULT_AUTO_REPLY=false     # القيم الافتراضية عند أول تشغيل فقط
DEFAULT_APPROVAL_MODE=true
```

انسخ `.env.example` إلى `.env` واملأه. ولإعادة التهيئة لاحقًا: `python main.py --reset`.
ولفحص الإعداد دون تشغيل البوت: `python main.py --check`.

### استخدام اشتراك ChatGPT بدل مفتاح API (اختياري)
```bash
npm install -g @openai/codex
codex login                  # اختر "Sign in with ChatGPT"
```
ثم في `.env`: `MODEL_BACKEND=codex` (أو اختر مزوّد **Codex** من `/ai`). ملاحظة:
هذا المسار أبطأ من API، وحدود الاشتراك تنطبق، والبحث بالـ Embeddings غير متاح
(يعمل البحث بالكلمات المفتاحية تلقائيًا). راجع شروط استخدام OpenAI قبل استخدامه
لخدمة عملاء حقيقية.

## التشغيل الدائم (سيرفر / VPS / Docker)

**بـ Docker (الأسهل):**
```bash
cp .env.example .env      # املأ BOT_TOKEN والمفتاح
docker compose up -d --build
docker compose logs -f    # لمشاهدة كود الملكية في أول تشغيل
```

**بـ systemd على سيرفر Linux:**
```ini
# /etc/systemd/system/smartel.service
[Unit]
Description=SmarTel Telegram Business assistant
After=network-online.target

[Service]
WorkingDirectory=/opt/Tg-bot-ai
ExecStart=/opt/Tg-bot-ai/.venv/bin/python main.py
Restart=always
RestartSec=5
User=smartel

[Install]
WantedBy=multi-user.target
```
```bash
sudo systemctl enable --now smartel && journalctl -u smartel -f
```

⚠️ لا تشغّل نسختين من البوت بنفس التوكن في الوقت نفسه — تيليجرام يوقف الاثنين بخطأ
`409 Conflict`.

### حفظ البيانات قبل كل deploy واستعادتها
البيانات ليست داخل صورة Docker؛ مكانها `storage/` (قاعدة SQLite الرئيسية، قواعد
المشرفين المنفصلة مثل `smartel.tenant-<id>.db`، وملفات رفع قاعدة المعرفة). Compose
يربط هذا المجلد بـ `/app/storage`، لذلك يبقى مع إعادة بناء الصورة إذا ظل مجلد التخزين
نفسه. على Railway أو أي PaaS، أنشئ **Persistent Volume** واربطه دائمًا على
`/app/storage`؛ من دون Volume دائم، أي deploy قد يبدأ بمجلد فارغ.

قبل النشر، خذ نسخة ZIP خارج مجلد التخزين/الـ Volume:

```bash
python3 scripts/backup_data.py --storage ./storage --output ./backups
```

على Docker، نفّذ الأمر على المضيف حيث يوجد مجلد `storage`، أو شغّله داخل الحاوية مع
توجيه `--output` إلى مكان دائم آخر. تأكد أن ملف `alfiqi-ai-backup-*.zip` موجود خارج
بيئة النشر المؤقتة، ثم انسخه إلى جهازك أو تخزين سحابي خاص. للاستعادة: أوقف البوت،
فك الـ ZIP داخل مجلد التخزين الصحيح مع الحفاظ على المسارات، ثم شغّل البوت.

ملف `.env` لا يدخل في النسخة عمدًا: احتفظ به منفصلًا وبشكل آمن، خصوصًا
`SMARTEL_FERNET_KEY`؛ من دونه قد لا يمكن فك تشفير مفاتيح API المحفوظة. النسخة
الاحتياطية لا تحمي من ضياعها إذا حفظتها داخل نفس الـ Volume الذي تحذفه المنصة.

## استكشاف الأخطاء

| المشكلة | السبب والحل |
|---|---|
| لا تصلك أي رسالة من العملاء | تأكد من تشغيل **Business Mode** في BotFather، وأن الربط تم من **Telegram Business ← Chat Bots**، وأن حسابك **Premium**. |
| البوت يقرأ ولا يرد | فعّل **«Allow bot to reply to messages»** في صلاحيات البوت داخل إعدادات Telegram Business، وتأكد بـ `/status`. |
| يرد بلا ذكاء اصطناعي أو يعتذر | المفتاح غير صالح أو انتهى الرصيد: `/ai` ← **Test connection**، أو `/health`. |
| «المفتاح غير مقبول» رغم أنني أنشأته الآن | البوت الآن يشرح **السبب**: لا يوجد رصيد في الحساب، أو المفتاح من مزوّد آخر، أو الحساب لم يُوثَّق، أو اسم الموديل خاطئ، أو تجاوزت الحد، أو دولتك محظورة. اقرأ نقاط **How to fix it** تحت الرسالة، وانظر جدول «المفتاح لا يعمل» بالأسفل. |
| لا أملك بطاقة بنكية ولا رصيد | أرسل `/freeai` واختر **Google Gemini** أو **Groq** أو **Cerebras** (مجاني بالإيميل/حساب جوجل)، أو **Pollinations** الذي لا يحتاج مفتاحًا إطلاقًا. ضغطة واحدة تنقل البوت وتطلب المفتاح الجديد. |
| اسم الموديل مرفوض | `/ai` ← 🧠 Change model ← **🔄 Load models from the provider**: يجلب لك الأسماء المتاحة لمفتاحك. |
| لا يرد في محادثة معيّنة | المحادثة موقوفة (تدخّل سابق) — `/chats` ثم إلغاء الإيقاف، أو `/handback <chat_id>`. |
| «409 Conflict» في السجلات | نسخة أخرى من البوت تعمل بنفس التوكن — أوقفها. |
| الردود لا تعرف معلوماتك | أضف المحتوى: `/faq_add` للأسئلة المتكررة و`/kb_upload` للملفات، أو ارفع `strict_kb_mode`. |
| الرد بصيغة غريبة أو مقطوع | ارفع `max_reply_chars` من `/settings`، أو اختر موديلًا أفضل من `/ai`. |
| نسيت كود الملكية | أوقف البوت وأعد تشغيله — يُطبع كود جديد (ما دام لم يُطالب بالملكية بعد). |

### «المفتاح لا يعمل» — ماذا يقول لك البوت الآن

| الرسالة التي تظهر | معناها | الحل |
|---|---|---|
| `the account has no credit left or its free quota is used up` | المفتاح سليم لكن لا يوجد خلفه رصيد/حصة. شائع في OpenAI وAnthropic وDeepSeek وTogether — **اشتراك ChatGPT أو Claude ليس رصيد API**. | اشحن الرصيد، أو اضغط أحد أزرار المزودين المجانيين 🆓 التي تظهر مع نفس الرسالة (أو أرسل `/freeai`). |
| `That is your Telegram bot token (from @BotFather), not an AI API key` | لصقت **توكن البوت** (`123456789:AA…`) في خانة مفتاح الذكاء الاصطناعي. | لا يوجد ما يُصلح في تيليجرام — الصق مفتاح **مزوّد الذكاء الاصطناعي**. البوت يتعرّف على شكل التوكن ويقول لك هذا قبل إرسال أي طلب. |
| `This looks like a key for <provider>, but you are adding it to <other>` | المفتاح يتبع مزوّدًا آخر (مثل مفتاح Gemini الذي يبدأ بـ `AIza` أثناء اختيار Groq). | بدّل إلى المزوّد صاحب المفتاح، أو استخرج مفتاحًا للمزوّد المختار. |
| `rejected this API key (HTTP 401/403)` | المفتاح نفسه خطأ: منتهي، ملغى، منسوخ بمسافات، أو **من مزوّد آخر**. | انسخه مرة أخرى من لوحة المزوّد الصحيحة — الرسالة تذكر لك الرابط بالضبط. |
| `Finish the account verification first` | المزوّد ما زال يطلب توثيق الإيميل/رقم الهاتف (مثل Mistral). | وثّق الحساب ثم أعد إرسال المفتاح. |
| `rejected the model name` | مفتاحك لا يملك صلاحية هذا الموديل، أو اسمه مختلف عند هذا المزوّد. | `/ai` ← 🧠 Change model ← **🔄 Load models from the provider**. |
| `hit a rate/quota limit` أو `rate limiting the bot right now` | وصلت لحد الطبقة المجانية (في الدقيقة/اليوم). **لا يوجد عطل** — يُصفَّر وحده. | انتظر قليلًا، أو انتقل إلى Gemini/Groq/Cerebras لحصة يومية أكبر. |
| `refused the request because of your country/region` | المزوّد لا يخدم منطقتك. | غيّر المزوّد — المجانية المذكورة أعلاه تعمل على نطاق واسع. |
| `404 — the base URL or the endpoint path is wrong` | الرابط خاطئ (عادةً ينقصه `/v1`). | صحّح الرابط: `/ai` ← 🌐 Set base URL (لخيار `custom`). |
| `Could not reach the provider` | مشكلة شبكة/DNS/فايروول في الجهاز الذي يشغّل البوت. | تحقق من اتصال الإنترنت على ذلك الجهاز. |

> نفس التشخيص يظهر في `/health`، وفي `python main.py --check`، وفي الإشعار الذي
> يصلك عند فشل توليد رد لأحد العملاء.

## الخصوصية والأمان

- البوت يستخدم **Telegram Bot API الرسمي** فقط: لا تسجيل برقم الهاتف، لا كود دخول،
  لا جلسة Userbot.
- الرسائل تُخزَّن محليًا في قاعدة بيانات SQLite على جهازك (`storage/smartel.db`) —
  لا تُرسل لأي طرف ثالث إلا لمزوّد الذكاء الاصطناعي الذي اخترته (لتوليد الرد فقط).
- المفاتيح تُخزَّن مشفّرة إذا ضبطت `SMARTEL_FERNET_KEY`، وتُخفى في السجلات، ولا
  تُصدَّر أبدًا في `/export`.
- التحكم بالبوت مقصور على المالك (رقمك أو كود الملكية)، وأي شخص آخر يراسل البوت
  مباشرة يحصل على رسالة توضيحية فقط.

## للمطوّرين

```bash
pip install -r requirements-dev.txt
pytest -q                     # كامل حزمة الاختبارات
pytest -q tests/integration   # اختبار تكاملي من التركيب حتى الرد
python main.py --check        # فحص الإعداد والاتصال دون تشغيل
```

البنية: `handlers/` (أوامر المالك، لوحات تيليجرام، مسار الرسائل الواردة)،
`services/` (الذكاء الاصطناعي ومزوّدوه، قاعدة المعرفة، الردود الجاهزة، الذاكرة،
الحدود، تجميع الرسائل)، `database.py` (SQLite)، `security.py` (الملكية)،
`telegram_api.py` (إرسال آمن مع تقسيم الرسائل وتصحيح HTML).
